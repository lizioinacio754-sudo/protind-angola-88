# PROTIND Angola (88)

Cria uma aplicação web profissional chamada PROTIND

(Plataforma de Proteção Inteligente do Território).

O objetivo é organizar o território de Angola e ajudar

na preservação ambiental através da inteligência artificial.

Cria uma interface moderna, responsiva e em português,

com as seguintes secções:

1. Painel principal com indicadores ambientais.

2. Mapa de Angola.

3. Gestão de províncias e municípios.

4. Registo de ocorrências ambientais.

5. Gestão de projetos de preservação ambiental.

6. Secção de análises e recomendações por inteligência artificial.

7. Menu lateral com navegação entre as secções.

Utiliza tons de verde, branco e azul, com um estilo

profissional e organizado.

Por enquanto, cria apenas a interface visual com dados

demonstrativos claramente identificados. Não cries outra

base de dados e não alteres a base de dados existente

no Neon. Ainda não ligues a aplicação ao banco de dados.
